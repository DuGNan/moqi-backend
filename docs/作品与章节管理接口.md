# 作品与章节管理接口

## 适用范围

本契约定义作品与章节的标题修改和逻辑删除能力。删除不会物理清理正文、讨论、规划、生成结果或知识层历史数据。

## 修改标题

- `PUT /api/works/{workId}`
- `PUT /api/chapters/{chapterId}`

请求体：

```json
{
  "title": "新标题",
  "baseVersion": 0
}
```

标题会去除首尾空白，不能为空，最长 200 个 Unicode 字符。成功后返回更新后的详情和递增后的 `version`。

## 删除资源

- `DELETE /api/works/{workId}?baseVersion=0`
- `DELETE /api/chapters/{chapterId}?baseVersion=0`

成功响应为 `ApiResponse<Void>`，其中 `data` 为 `null`。作品删除会在同一事务中逻辑删除其全部未删除章节；章节删除不会重排其他章节编号。已删除章节的编号不会再次分配。

删除前会检查活动任务：`ai_tasks` 的 `queued/running`，以及 Agent Run 的 `queued/running/waiting` 均会返回 HTTP 409。已删除资源或重复删除返回 404。

## 并发与错误码

- `WORK_VERSION_CONFLICT`：作品的 `baseVersion` 已过期，HTTP 409。
- `CHAPTER_VERSION_CONFLICT`：章节的 `baseVersion` 已过期，HTTP 409。
- `AI_TASK_STATE_CONFLICT`：存在未结束任务，HTTP 409。
- `WORK_NOT_FOUND`、`CHAPTER_NOT_FOUND`：资源不存在或已删除，HTTP 404。

所有修改与删除写入都以资源 ID、未删除状态和 `baseVersion` 为条件；成功后递增版本号。删除完成后，作品和章节的基础入口均不可继续访问。
