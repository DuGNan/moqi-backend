# 场景小说生成接口

## 适用范围

本接口以已发布的章节场景规划为生成入口，常规全量请求一次生成完整章节候选，局部重生成保留逐场景兼容链。所有结果均可追溯、可取消、可重试；不会直接写入 `chapters.content`，也不会修改设定、伏笔、章节摘要或关键事件。

## 创建与查询

- `POST /api/chapters/{chapterId}/capacity-assessments`：按当前或指定已发布 `scenePlanNo`、篇幅预设和幂等键创建容量评估。
- `GET /api/chapter-capacity-assessments/{assessmentId}`：刷新或重启后读取持久化状态、四类结论、来源/Brief 指纹、结构化理由、安全降级信息以及 `currentAttempt`、`retryable`；`POST .../{assessmentId}/cancel` 和 `POST .../{assessmentId}/retry` 分别取消运行和按公开尝试次数重试真实失败的语义步骤。
- `POST /api/chapters/{chapterId}/generations`：创建批次。请求必须给出 `idempotencyKey`；`selectionMode` 省略时按 `all` 处理并使用 `whole_chapter_once` 一次生成完整章节。可用 `includeCurrentContent=true` 把当前正文的版本、哈希和内容冻结为参考基稿，或用 `baseGenerationId` 引用同章节、同规划版本的既有候选，两者不能同时使用。`continue_from` 需要 `fromSceneKey`；`rewrite_selected` 需要非空 `sceneKeys` 和可复用的 `baseGenerationId`，两者继续使用逐场景兼容链。
- `GET /api/generations/{generationId}`：读取持久化整章候选、规划/基础批次/Agent Run/来源快照引用、`contentAssemblyMode`、模板、模型调用以及 `currentAttempt`、`retryable`；刷新和服务重启后以此资源为准。
- `GET /api/chapters/{chapterId}/generations/latest-active`：按章节恢复最新 `queued`、`running`、`failed` 或 `preview` 批次，返回生成/任务/Run 引用和安全重试元数据；不存在时返回显式空态，已采纳、拒绝、取消和已替代批次不会抢占恢复入口。
- `GET /api/generations/{generationId}/scenes`：按场景计划顺序读取候选清单。
- `GET /api/generations/{generationId}/scenes/{sceneId}`：读取单个候选的状态、上下文快照、模板版本、调用指标与来源候选引用；正文通过原生成详情读取，SSE 只通知资源变化。
- `POST /api/generations/{generationId}/cancel`：取消仍在排队或运行的批次，并传播给 Agent Run 与 Provider 流。
- `POST /api/generations/{generationId}/scenes/{sceneId}/retry`：基于预期尝试次数重试单场景的失败步骤。
- `POST /api/generations/{generationId}/retry`：提交 `expectedAttempt`，只重试失败的 `generate_chapter` 步骤，并继续使用原批次冻结输入。
- `POST /api/generations/{generationId}/cohere/retry`：兼容重试历史逐场景批次的整章收束步骤。
- `POST /api/generations/{generationId}/regenerate`：基于路径中的原批次创建新的 `continue_from` 或 `rewrite_selected` 批次。请求中的 `baseGenerationId` 若提供，必须等于路径 ID。

## 响应与错误

创建和重新生成返回 `generationId`、`aiTaskId`、`agentRunId`、章节规划版本 ID 与批次状态。运行期间可收到临时 `generation.delta`，但刷新、断线重连和重启恢复始终重新读取持久化 generation；生命周期事件不包含完整 Prompt、密钥或隐藏推理。

资源不存在返回 404；非法场景选择返回 400；运行状态、版本或已固定的模型配置发生竞争/过期返回 409。调用必须使用当前可用的 Provider V2 配置；批次会持久化安全配置描述（供应商、模型、配置和凭据版本），绝不持久化 API Key 或完整 prompt。

## 人工确认边界

创建容量评估和生成批次时由作者选择章节目标篇幅：`about_1500`、`about_3000`、`about_5000` 或 `custom`。自定义目标须在 500 到 20000 字之间。评估结论为 `fits`、`too_dense`、`too_thin` 或 `requires_long_context`，并返回建议区间、事件权重、可压缩项、不可压缩因果节点、拆章建议与可用动作。结论始终是候选：服务端不自动修改规划，`too_dense` 只有请求显式提交 `capacityAssessmentId` 和 `capacityDecision=continue_long_chapter` 才允许生成；`requires_long_context` 拒绝生成并保留触发 #112 的证据；`too_thin` 可自然生成短章。未提供评估 ID 的兼容请求只在确定性基线为 `fits` 或 `too_thin` 时放行。

正文 Prompt 只接收批次冻结的人类可读 Brief、容量软区间、事件权重、不可压缩因果节点和可选参考基稿，不投放孤立的 ScenePlan JSON，也不按场景数量平均分配目标。模型必须只输出小说正文；JSON、Markdown、分析、说明、Prompt 回显或空输出会使步骤失败并等待显式重试。偏离软区间不会触发自动扩写/压缩，也不会单独导致生成失败。`maxOutputTokens` 仅作为 Provider 安全上限。生成批次冻结容量结果、输入指纹和作者决定，运行期来源变化不会重算既有批次。

新全量批次使用 `whole-chapter-v1` 模板和 `load_generation -> generate_chapter -> finalize_generation`，把模型调用 ID、finish reason 和模板版本直接记录在 generation；不创建伪装成已生成内容的场景行。历史 `scene_join_legacy`、`cohesive_chapter` 及其场景快照保持可读。完成生成后候选保持既有 `preview`，独立评价结论为 `pass` 或非阻塞 `warning` 才能采纳；正文写入仍经过用户显式采纳及 `baseVersion` 校验。
## 正文一致性评价

- 完整正文生成完成后自动创建整章评价；手动 `POST /api/chapters/{chapterId}/generations/{generationId}/evaluation-reports` 仍可用 `idempotencyKey` 安全复用或恢复评价，可选指定 `generationSceneId` 兼容旧场景报告。
- `GET /api/chapters/{chapterId}/generations/{generationId}/evaluation-reports/latest` 和按 `reportId` 查询：读取 `pass/warning/needs_revision/needs_human` 结论、Finding、正文哈希、Brief/来源指纹、规则/评价器版本、独立模型调用和安全失败摘要。
- `POST .../{reportId}/retry`、`POST .../{reportId}/cancel`：恢复失败的语义评价步骤或取消运行中的评价。
- `whole-chapter-evaluator-v3` 明确要求 Finding 的全部字段和 JSON 类型；只执行单向收紧的安全规范化：把带非空 `text` 且偏移合法的证据对象收敛为字符串；整章来源 `sceneId=null` 时移除模型误填的场景标识；把来源快照无法验证的 `storyFactRef` 收敛为 `null`；在 Finding 不阻塞采纳时关闭模型误开的自动修订标志。Agent Step 输出保存全部规范化字段路径；缺字段、错误枚举、错误引用或无法确定的形态按安全类别和字段路径失败，整批 Finding 不会部分放行。
- `needs_revision` 只形成后续 #106 的有界修订输入，本流程不创建或采纳修订稿；既有 `GET .../{reportId}/revision-candidate` 仅兼容读取历史 #46 局部候选。

## 场景候选读取

`GET /api/generations/{generationId}/scenes` 和 `GET /api/generations/{generationId}/scenes/{sceneId}` 返回每个场景的持久化候选正文 `generatedContent`、当前步骤尝试次数 `currentAttempt`、是否可重试 `retryable` 以及安全错误摘要 `errorCode`、`errorMessage`。

- `completed` 与 `copied` 场景的 `generatedContent` 是可预览候选，尚未采纳时不会修改章节正文。
- 仅场景状态为 `failed`、同一 `generate_scene:{sceneKey}` 的最新步骤也为失败且该步骤允许重试时，`retryable` 才为 `true`。
- `canceled` 场景不可重试；客户端只可把服务端返回的 `currentAttempt` 作为 `expectedAttempt` 提交。
- SSE 只用于即时提示；刷新、重连和失败后必须重新读取这些持久化资源。
