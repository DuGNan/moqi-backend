# 场景小说生成接口

## 适用范围

本接口以已发布的章节场景规划为唯一生成依据，创建的始终是可追溯、可取消、可重试的场景正文候选；不会直接写入 `chapters.content`，也不会修改设定、伏笔、章节摘要或关键事件。

## 创建与查询

- `POST /api/chapters/{chapterId}/generations`：创建批次。请求必须给出 `idempotencyKey` 和 `selectionMode`。`all` 生成全部已规划场景；`continue_from` 需要 `fromSceneKey`；`rewrite_selected` 需要非空 `sceneKeys` 和可复用的 `baseGenerationId`。
- `GET /api/generations/{generationId}/scenes`：按场景计划顺序读取候选清单。
- `GET /api/generations/{generationId}/scenes/{sceneId}`：读取单个候选的状态、上下文快照、模板版本、调用指标与来源候选引用；正文通过原生成详情读取，SSE 只通知资源变化。
- `POST /api/generations/{generationId}/cancel`：取消仍在排队或运行的批次，并传播给 Agent Run 与 Provider 流。
- `POST /api/generations/{generationId}/scenes/{sceneId}/retry`：基于预期尝试次数重试单场景的失败步骤。
- `POST /api/generations/{generationId}/regenerate`：基于路径中的原批次创建新的 `continue_from` 或 `rewrite_selected` 批次。请求中的 `baseGenerationId` 若提供，必须等于路径 ID。

## 响应与错误

创建和重新生成返回 `generationId`、`aiTaskId`、`agentRunId`、章节规划版本 ID 与批次状态。所有状态变动通过章节 SSE 发布 `generation.started`、`generation.updated`、`generation.failed` 或 `generation.canceled`，事件不包含正文、完整 prompt、密钥或隐藏推理。

资源不存在返回 404；非法场景选择返回 400；运行状态、版本或已固定的模型配置发生竞争/过期返回 409。调用必须使用当前可用的 Provider V2 配置；批次会持久化安全配置描述（供应商、模型、配置和凭据版本），绝不持久化 API Key 或完整 prompt。

## 人工确认边界

每个场景候选均固定关联场景计划版本、Story Context Snapshot、Provider/模型配置版本和 `scene-novel-v1` 模板版本。完成生成仅表示候选可预览，不等于正式正文采纳；正文写入仍经过既有的显式保存或采纳流程及其 `baseVersion` 校验。
