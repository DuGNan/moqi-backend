# 数据库设计变更记录

## 2026-08-29：支持章节暂缓命名与标题候选（V53）

- `chapters.title` 改为可空，未命名章节仍可继续正文流程。
- 新增可恢复的标题候选批次与候选表，保存来源正文快照、幂等键与明确采用状态。

## 2026-08-28：绑定正式正文冻结生成依据（V51）

- `chapters` 新增 `formal_source_generation_id`，使正式正文与候选读取同一份生成时冻结依据。
- revision 切换和候选直接采纳在正文 CAS 成功时同步更新来源；历史数据仅按已发布 revision、已完成采纳或 accepted generation 的可追溯记录回填。

## 2026-08-29：冻结选区协助的正文对象会话历史（V52）

- `chapter_selection_assistance` 新增 `conversation_history_json`，冻结 assistance 创建时当前 `prose_object` 会话实际采用的 user/assistant 历史。
- Provider 调用按角色发送冻结历史后再发送当前 User Prompt；重试和服务恢复复用同一快照，不读取后来新增消息改变既有请求。
- 五个选区动作的请求与结果均写回绑定对象会话；修改结果明确保持为尚未应用、尚未保存的候选提案。

## 2026-08-26：正文对象独立会话与消息重放（V50）

- `chapter_conversations` 新增 `target_object_id` 和活动正文作用域生成列；唯一约束保证正式正文与每个候选分别只有一个活动 `prose_object` 会话。
- `chapter_conversation_messages` 新增会话内唯一的 `client_message_id`，网络重放和并发提交复用原用户消息及其模型任务。
- 历史 `chapter_co_creation` 会话保持原语义，不迁移或复制到正文对象会话；正式正文和既有候选在首次读取/发送时按需创建独立会话。

## 2026-08-22：异步失败诊断引用（V46）

- `ai_tasks` 与 `agent_runs` 新增可空 `diagnostic_ref` 及唯一索引，历史记录保持为空。
- 异步失败在终态 CAS 中首次写入随机不透明引用；同一失败的轮询、刷新和 SSE 复用该值，步骤重试不清除或覆盖。
- 引用不编码任务、Run、模型、Provider、正文、Prompt、字段详情或凭据，不新增作者诊断详情接口。

## V38：增加整章质量评价绑定与失败追溯

- `chapter_generation_evaluation_reports` 增加正文哈希、Brief/来源指纹、独立模型调用和安全失败摘要。
- 报告可按 generation、正文哈希、规则版本和 Evaluator 版本追溯；模型调用通过外键关联 `llm_model_calls`。
- 历史报告仅回填已有输入指纹，不伪造 Brief 指纹或评价通过结论。

## V35：增加章节容量评估

- 新增 `chapter_capacity_assessments`，冻结同作品已发布规划、Chapter Generation Brief、目标篇幅、输入指纹和评估器版本。
- 记录 Agent Run、AI Task、模型调用、四类候选结果、安全降级原因与失败摘要；章节范围幂等键避免重复评估。
- 容量结果不写回章纲或场景规划，只在作者创建正文生成批次时作为门禁和冻结依据。

## V20：增加 LLM 调用与估算成本观测

- `llm_model_calls` 增加用户、作品、章节、工作流、操作、逻辑调用、尝试序号和估算成本字段，并补充最近调用与聚合查询索引。
- 新增 `llm_model_prices`，按供应商、模型、币种和生效区间保存版本化单价；调用记录通过外键固定实际估算使用的价格版本。
- 同一 `logical_call_id` 下以 `attempt_no` 唯一标识物理尝试，失败、取消、超时和限流不会与后续成功尝试合并。

## V18：支持从已确认共识生成首版章纲候选

- `chapter_outline_candidates` 增加 `candidate_type` 与章节级 `idempotency_key` 唯一约束，旧记录默认识别为 `adjustment`。
- `base_outline_id`、`base_outline_revision`、`base_outline_content` 改为可空，使 `initial` 候选在正式大纲创建前保存。
- 增加同章候选类型和状态查询索引；首版确认仍依赖 `chapter_outlines.chapter_id` 唯一约束防止并发重复落版。

## V17：增加章节讨论自适应回复策略

- 增加 `V17__add_adaptive_reply_policy.sql`：新增 `reply_policy_preferences` 分层回复深度偏好，并为 `llm_model_calls` 增加 conversation reply 的任务、会话、策略与安全范围摘要审计字段。

## 2026-08-15

- 增加 `V41__add_prose_impact_propagation.sql`，新增正文 revision 影响报告、精确事实变化证据、受影响资产和 Story Release 知识来源映射；增加 `V42__bind_prose_impact_source_graph.sql`，在不改写已应用 V41 的前提下增量持久化全作品 V24 来源图指纹和经同作品、邻接边界校验的 `affectedChapterIds`。报告输入身份同时绑定 baseline Story Release/revision、正文哈希、分析器版本与来源图；缺少 V42 来源图身份的旧报告安全视为 stale。
