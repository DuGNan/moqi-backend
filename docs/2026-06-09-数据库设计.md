# 墨契 / Moqi 当前数据库设计

**版本**：V1.2  
**日期**：2026-07-05  
**适用范围**：墨契 Web App 后端 P0 主流程当前库结构

---

## 一、适用范围

本文档描述墨契 Web App 后端 P0 主流程的当前数据库结构，重点包括：

- 当前有哪些表。
- 每张表做什么。
- 每个字段是什么意思。
- 表之间如何关联。
- 典型业务数据如何存储。

## 二、全局约定

### 2.1 主键与时间字段

所有业务表默认使用自增 `id` 作为主键和表间关联键。

所有业务表默认包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT AUTO_INCREMENT` | 主键 ID，数据库内部关联使用。 |
| `gmt_create` | `DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP` | 创建时间。 |
| `gmt_modified` | `DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新时间，记录更新时自动刷新。 |

当前 P0 数据库不保留 `biz_id`。接口、服务和表间关系统一使用自增 `id`。

### 2.2 通用控制字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `deleted` | `TINYINT NOT NULL DEFAULT 0` | 逻辑删除标记，`0` 表示未删除，`1` 表示已删除。 |
| `version` | `INT NOT NULL DEFAULT 0` | 通用乐观锁版本号。章节正文当前使用 `chapters.version` 控制保存冲突。 |
| `revision` | `INT NOT NULL DEFAULT 0` | 资源内容修订版本。当前用于 `chapter_outlines` 的大纲编辑冲突控制。 |

### 2.3 JSON 字段边界

当前 P0 不把所有结构都拆成子表。以下内容使用 JSON 保存：

- `chapter_outlines.outline_content`：正式章节大纲结构。
- `chapter_generations.basis_snapshot_json`：生成正文时使用的大纲和约束快照。
- `user_configs.config_value`：用户配置值。

如果 JSON 内部字段以后变成稳定查询条件，再通过独立 issue 拆列或拆表。

## 三、表关系总览

当前 P0 数据库共有 14 张业务表：

| 表名 | 中文名 | 作用 |
| --- | --- | --- |
| `works` | 作品表 | 保存作品基础信息。 |
| `chapters` | 章节表 | 保存章节基础信息和正文。 |
| `chapter_outlines` | 章节大纲表 | 保存用户确认、可编辑、可用于生成正文的正式章节大纲。 |
| `chapter_conversations` | 章节会话表 | 保存章节共创或章节编辑 AI 会话。 |
| `chapter_conversation_messages` | 章节会话消息表 | 保存会话内的用户、助手、系统消息。 |
| `chapter_briefs` | 章节共创收束摘要表 | 保存 AI 或会话收束出的摘要、候选结构卡或中间结果。 |
| `chapter_generations` | 章节正文生成记录表 | 保存基于大纲生成正文的任务参数、依据快照和生成结果。 |
| `user_configs` | 用户配置表 | 保存用户级模型配置、写作偏好、外观和同步配置。 |
| `ai_tasks` | AI 异步任务表 | 保存 AI 回复、正文生成、大纲刷新等异步任务状态。 |
| `setting_candidates` | 待确认设定表 | 保存从正文、会话或生成结果中抽取出的候选设定。 |
| `setting_entries` | 作品级正式设定表 | 保存用户确认后的正式人物、地点、组织、规则和物品等设定。 |
| `foreshadowing_items` | 伏笔与线索表 | 保存伏笔、线索、来源位置和回收状态。 |
| `chapter_summaries` | 章节摘要表 | 保存每章摘要、人物变化、新增设定和未决问题。 |
| `chapter_key_events` | 章节关键事件表 | 保存每章关键事件，用于后续时间线和上下文检索。 |

核心关系：

```text
works 1 - N chapters
chapters 1 - 1 chapter_outlines
chapters 1 - N chapter_conversations
chapter_conversations 1 - N chapter_conversation_messages
chapters 1 - N chapter_briefs
chapters 1 - N chapter_generations
chapter_outlines 1 - N chapter_generations
works 1 - N setting_candidates
works 1 - N setting_entries
works 1 - N foreshadowing_items
chapters 1 - 1 chapter_summaries
chapters 1 - N chapter_key_events
ai_tasks 可关联 message / generation 的异步结果
```

阶段判断：

- 当前库已覆盖 P0 写作主流程与第一版必通知识层，可保存作品、章节正文、章节大纲、章节摘要、关键事件、设定、伏笔、会话、生成记录和 AI 任务基础状态。
- 角色状态快照、叙事线程、时间线事件和知识巡检结果尚未落库，属于第一版核心增强或后续独立能力。
- 当前接口文档应围绕已落库表和当前 P0 流程生成；编辑建议、LLM 调用日志、token 汇总、角色状态、叙事线程、时间线和知识巡检只作为后续能力说明，不生成当前正式接口。

## 四、表设计详情

### 4.1 `works` 作品表

作用：

- 保存作品基础信息。
- 作为章节、大纲、会话、生成记录的作品级根节点。
- 当前不保存章节数、总字数等统计冗余字段。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `title` | `VARCHAR(255)` | 作品标题。 |
| `status` | `VARCHAR(32)` | 作品状态，默认 `draft`。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引：

| 索引 | 字段 | 作用 |
| --- | --- | --- |
| `idx_works_status_gmt_modified` | `status, gmt_modified` | 按状态和更新时间查询作品。 |

### 4.2 `chapters` 章节表

作用：

- 保存章节标题、序号、正文和工作流状态。
- `content` 是章节正文唯一事实源。
- 不拆段落主表，段落结构由前端或运行时派生。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `work_id` | `BIGINT` | 所属作品 ID，关联 `works.id`。 |
| `title` | `VARCHAR(255)` | 章节标题。 |
| `chapter_no` | `INT` | 章节序号，同一作品内唯一。 |
| `chapter_type` | `VARCHAR(32)` | 章节类型：`dedication` 献词，`prologue` 序幕，`chapter` 正文，`epilogue` 尾声，`other` 其他。 |
| `content` | `LONGTEXT` | 章节正文，章节内容唯一事实源。 |
| `workflow_status` | `VARCHAR(32)` | 章节工作流状态，默认 `co_creation`。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 章节正文保存的乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `uk_chapters_work_id_chapter_no` | `work_id, chapter_no` | 保证同一作品内章节序号唯一。 |
| `idx_chapters_workflow_status` | `work_id, workflow_status` | 查询作品下指定工作流状态章节。 |
| `idx_chapters_work_type` | `work_id, chapter_type` | 查询作品下指定章节类型。 |
| `fk_chapters_work_id` | `work_id -> works.id` | 章节归属作品。 |

### 4.3 `chapter_outlines` 章节大纲表

作用：

- 保存正式章节大纲。
- 一章最多一条当前正式大纲。
- 支撑大纲读取、保存、刷新和生成正文。
- `revision` 用于大纲乐观锁。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `work_id` | `BIGINT` | 所属作品 ID，关联 `works.id`。 |
| `chapter_id` | `BIGINT` | 所属章节 ID，关联 `chapters.id`。 |
| `outline_status` | `VARCHAR(32)` | 大纲状态：`draft` 草稿，`confirmed` 已确认，`outdated` 已过期。 |
| `outline_content` | `JSON` | 大纲内容，包含本章目标、场景、人物变化、节奏、约束和未决问题。 |
| `revision` | `INT` | 大纲修订版本号，用于乐观锁。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `uk_chapter_outlines_chapter_id` | `chapter_id` | 保证一章只有一条正式大纲。 |
| `idx_chapter_outlines_work_gmt_modified` | `work_id, gmt_modified` | 按作品查询最近更新的大纲。 |
| `idx_chapter_outlines_status_gmt_modified` | `outline_status, gmt_modified` | 按状态查询大纲。 |
| `fk_chapter_outlines_work_id` | `work_id -> works.id` | 大纲归属作品。 |
| `fk_chapter_outlines_chapter_id` | `chapter_id -> chapters.id` | 大纲归属章节。 |

`outline_content` 结构示例：

```json
{
  "goal": "隐藏房间回应林风，姚宁第一次改写自己的判断。",
  "coreConflict": "姚宁不愿承认隐藏房间回应，但事实开始逼近她。",
  "scenes": [
    {
      "id": "scene_1",
      "title": "怀表出现反应",
      "content": "林风靠近隐藏房间时，怀表先出现细微变化。",
      "tags": ["增加悬念"]
    }
  ],
  "characterChange": "姚宁从怀疑变成动摇。",
  "emotionPace": "克制疑惑 -> 紧张确认 -> 关系松动",
  "constraints": ["姚宁不能突然完全信任", "不要提前解释隐藏房间规则"],
  "openQuestions": ["姚宁是否当场追问林风？"]
}
```

### 4.4 `chapter_conversations` 章节会话表

作用：

- 保存章节共创会话和章节编辑 AI 会话。
- 会话本身只保存归属、类型和状态，消息内容在 `chapter_conversation_messages`。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `work_id` | `BIGINT` | 所属作品 ID，关联 `works.id`。 |
| `chapter_id` | `BIGINT` | 所属章节 ID，关联 `chapters.id`。 |
| `conversation_type` | `VARCHAR(32)` | 会话类型：`chapter_co_creation` 章节共创，`chapter_editing` 章节编辑。 |
| `conversation_status` | `VARCHAR(32)` | 会话状态，默认 `active`。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `idx_chapter_conversations_chapter_status` | `chapter_id, conversation_status` | 查询章节下有效会话。 |
| `idx_chapter_conversations_work_gmt_modified` | `work_id, gmt_modified` | 查询作品下最近更新会话。 |
| `fk_chapter_conversations_work_id` | `work_id -> works.id` | 会话归属作品。 |
| `fk_chapter_conversations_chapter_id` | `chapter_id -> chapters.id` | 会话归属章节。 |

### 4.5 `chapter_conversation_messages` 章节会话消息表

作用：

- 保存会话中的每条消息。
- 支持章节共创和编辑页 AI 对话复用。
- 可以通过 `ai_task_id` 关联生成该消息或由该消息触发的 AI 任务。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `conversation_id` | `BIGINT` | 所属会话 ID，关联 `chapter_conversations.id`。 |
| `chapter_id` | `BIGINT` | 所属章节 ID，关联 `chapters.id`。 |
| `message_role` | `VARCHAR(32)` | 消息角色：`user` 用户，`assistant` 助手，`system` 系统。 |
| `content` | `LONGTEXT` | 消息正文。 |
| `ai_task_id` | `BIGINT` | 关联 AI 任务 ID，可为空。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `idx_ccm_conversation_gmt_create` | `conversation_id, gmt_create` | 按会话时间线读取消息。 |
| `idx_ccm_chapter_gmt_create` | `chapter_id, gmt_create` | 按章节读取消息历史。 |
| `idx_ccm_ai_task_id` | `ai_task_id` | 查询任务关联消息。 |
| `fk_ccm_conversation_id` | `conversation_id -> chapter_conversations.id` | 消息归属会话。 |
| `fk_ccm_chapter_id` | `chapter_id -> chapters.id` | 消息归属章节。 |
| `fk_ccm_ai_task_id` | `ai_task_id -> ai_tasks.id` | 消息关联任务。 |

### 4.6 `chapter_briefs` 章节共创收束摘要表

作用：

- 保存 AI 或会话讨论过程中整理出来的摘要、候选结构卡或中间结果。
- 不保存正式章节大纲。
- 正式章节大纲由 `chapter_outlines` 保存。

典型内容：

- 本章目标候选。
- 当前冲突总结。
- 会话收束出的生成建议。
- 用户尚未确认的结构卡。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `work_id` | `BIGINT` | 所属作品 ID，关联 `works.id`。 |
| `chapter_id` | `BIGINT` | 所属章节 ID，关联 `chapters.id`。 |
| `brief_status` | `VARCHAR(32)` | 摘要状态，默认 `draft`。 |
| `brief_content` | `LONGTEXT` | AI 或会话收束出的摘要、候选结构卡或中间结果。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `idx_chapter_briefs_chapter_status` | `chapter_id, brief_status` | 查询章节下指定状态摘要。 |
| `idx_chapter_briefs_work_gmt_modified` | `work_id, gmt_modified` | 查询作品下最近更新摘要。 |
| `fk_chapter_briefs_work_id` | `work_id -> works.id` | 摘要归属作品。 |
| `fk_chapter_briefs_chapter_id` | `chapter_id -> chapters.id` | 摘要归属章节。 |

### 4.7 `chapter_generations` 章节正文生成记录表

作用：

- 保存一次正文生成的参数、依据快照、状态和生成结果。
- 支持异步任务先创建记录，任务完成后再写入 `generated_content`。
- `basis_snapshot_json` 固化生成时的大纲依据，避免后续大纲变化影响历史生成记录。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `work_id` | `BIGINT` | 所属作品 ID，关联 `works.id`。 |
| `chapter_id` | `BIGINT` | 所属章节 ID，关联 `chapters.id`。 |
| `brief_id` | `BIGINT` | 关联章节收束摘要 ID，可为空。 |
| `outline_id` | `BIGINT` | 生成依据的正式章节大纲 ID。 |
| `outline_revision` | `INT` | 生成依据的大纲修订版本。 |
| `generation_status` | `VARCHAR(32)` | 生成状态，默认 `draft`。 |
| `generation_mode` | `VARCHAR(32)` | 生成模式，例如 `full_draft`、`segmented_draft`。 |
| `length_preset` | `VARCHAR(32)` | 字数预设，例如 `about_3000`。 |
| `custom_word_count` | `INT` | 自定义目标字数。 |
| `basis_snapshot_json` | `JSON` | 生成依据快照 JSON。 |
| `generated_content` | `LONGTEXT` | 生成正文内容，可为空。 |
| `word_count` | `INT` | 生成正文字数，默认 `0`。 |
| `ai_task_id` | `BIGINT` | 关联 AI 任务 ID，可为空。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `idx_chapter_generations_chapter_status` | `chapter_id, generation_status` | 查询章节下指定状态生成记录。 |
| `idx_chapter_generations_work_gmt_modified` | `work_id, gmt_modified` | 查询作品下最近生成记录。 |
| `idx_chapter_generations_brief_id` | `brief_id` | 查询摘要关联生成记录。 |
| `idx_chapter_generations_outline_id` | `outline_id` | 查询大纲关联生成记录。 |
| `idx_chapter_generations_ai_task_id` | `ai_task_id` | 查询任务关联生成记录。 |
| `fk_chapter_generations_work_id` | `work_id -> works.id` | 生成记录归属作品。 |
| `fk_chapter_generations_chapter_id` | `chapter_id -> chapters.id` | 生成记录归属章节。 |
| `fk_chapter_generations_brief_id` | `brief_id -> chapter_briefs.id` | 生成记录关联摘要。 |
| `fk_chapter_generations_outline_id` | `outline_id -> chapter_outlines.id` | 生成记录关联大纲。 |
| `fk_chapter_generations_ai_task_id` | `ai_task_id -> ai_tasks.id` | 生成记录关联任务。 |

### 4.8 `user_configs` 用户配置表

作用：

- 保存用户级配置。
- 首版承载模型配置、写作偏好、外观、同步配置。
- 暂不单独建 `model_providers`。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `user_id` | `VARCHAR(64)` | 用户 ID。当前用户来源可由后端安全上下文、SSO 或本地默认用户确定。 |
| `config_key` | `VARCHAR(128)` | 配置键，例如 `model.active`、`writing.preferences`、`appearance.preferences`。 |
| `config_value` | `JSON` | 配置值 JSON。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `uk_user_configs_user_key_deleted` | `user_id, config_key, deleted` | 同一用户同一配置键只保留一条未删除记录。 |
| `idx_user_configs_user_gmt_modified` | `user_id, gmt_modified` | 查询用户最近更新配置。 |

首批 `config_key`：

| 配置键 | 用途 |
| --- | --- |
| `model.active` | 当前模型服务配置。 |
| `writing.preferences` | 写作偏好。 |
| `appearance.preferences` | 外观配置。 |
| `sync.preferences` | 同步配置。 |

### 4.9 `ai_tasks` AI 异步任务表

作用：

- 保存 AI 异步任务状态。
- 支撑 AI 回复、正文生成、大纲刷新等任务轮询。
- 不保存完整模型调用日志和 token 统计。

字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `BIGINT` | 主键 ID。 |
| `task_type` | `VARCHAR(32)` | 任务类型。 |
| `task_status` | `VARCHAR(32)` | 任务状态：`queued` 排队中，`running` 运行中，`succeeded` 成功，`failed` 失败，`canceled` 已取消。 |
| `work_id` | `BIGINT` | 关联作品 ID，可为空。 |
| `chapter_id` | `BIGINT` | 关联章节 ID，可为空。 |
| `result_message_id` | `BIGINT` | 成功后生成的消息 ID，可为空。 |
| `result_generation_id` | `BIGINT` | 成功后生成的正文生成记录 ID，可为空。 |
| `result_suggestion_id` | `BIGINT` | 成功后生成的编辑建议 ID，可为空。当前 P0 暂无 `suggestions` 表，该字段仅作为预留，不作为当前接口生成依据。 |
| `error_code` | `VARCHAR(64)` | 失败错误码。 |
| `error_message` | `VARCHAR(500)` | 失败错误信息。 |
| `deleted` | `TINYINT` | 是否删除。 |
| `version` | `INT` | 乐观锁版本号。 |
| `gmt_create` | `DATETIME` | 创建时间。 |
| `gmt_modified` | `DATETIME` | 更新时间。 |

索引与约束：

| 名称 | 字段 | 作用 |
| --- | --- | --- |
| `idx_ai_tasks_chapter_status_gmt_create` | `chapter_id, task_status, gmt_create` | 查询章节下任务状态。 |
| `idx_ai_tasks_work_type_gmt_create` | `work_id, task_type, gmt_create` | 查询作品下某类任务。 |
| `idx_ai_tasks_status_gmt_create` | `task_status, gmt_create` | 查询待处理任务队列。 |
| `idx_ai_tasks_result_message_id` | `result_message_id` | 查询任务生成消息。 |
| `idx_ai_tasks_result_generation_id` | `result_generation_id` | 查询任务生成记录。 |
| `fk_ai_tasks_work_id` | `work_id -> works.id` | 任务关联作品。 |
| `fk_ai_tasks_chapter_id` | `chapter_id -> chapters.id` | 任务关联章节。 |
| `fk_ai_tasks_result_message_id` | `result_message_id -> chapter_conversation_messages.id` | 任务结果关联消息。 |
| `fk_ai_tasks_result_generation_id` | `result_generation_id -> chapter_generations.id` | 任务结果关联生成记录。 |

说明：

- `ai_tasks.result_suggestion_id` 为后续编辑建议预留，目前没有外键。
- `ai_tasks` 与消息、生成记录存在可空双向关联。创建异步任务时可先创建任务和业务记录，任务完成后再回填结果 ID。

核心字段：

| `chapter_id` | `BIGINT` | 来源章节 ID，可为空。 |

| `source_id` | `BIGINT` | 来源记录 ID。 |
| `source_content_revision` | `INT` | 来源正文修订版本。 |
| `source_start_offset` / `source_end_offset` | `INT` | 来源正文范围。 |

| `name` | `VARCHAR(255)` | 候选设定名称。 |

## 八、读取与写入要点

- 首页和作品概览中的章节数量、字数等统计，当前不在主表冗余保存，可查询或后续统计表补齐。
- 保存章节正文时使用 `chapters.version` 做冲突控制。
- 保存章节大纲时使用 `chapter_outlines.revision` 做冲突控制。
- 生成正文时应记录 `outline_id`、`outline_revision` 和 `basis_snapshot_json`。
- `chapter_briefs` 只保存 AI/会话中间收束，不作为正式大纲。
- 用户配置统一从 `user_configs` 按 `user_id + config_key + deleted=0` 读取。
- 导入既有小说时，章节正文仍写入 `chapters.content`；献词、序幕、正文和尾声用 `chapters.chapter_type` 区分。
- 作品级人物、地点、组织、规则、物品等长期资料写入 `setting_entries`，进入正式设定前可先写入 `setting_candidates`。
- 伏笔、线索和待回收内容写入 `foreshadowing_items`，通过来源章节与回收章节追踪叙事闭环。
- 长篇上下文检索优先使用 `chapter_summaries` 和 `chapter_key_events`，避免每次 AI 调用直接拼接整本正文。
