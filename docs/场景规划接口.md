# 场景规划接口

## 作品叙事规划

- `POST /api/works/{workId}/narrative-plans`：创建草稿。
- `GET /api/works/{workId}/narrative-plans/current`：读取当前发布版。
- `GET /api/works/{workId}/narrative-plans/{planId}`：读取指定版本。
- `PUT /api/works/{workId}/narrative-plans/{planId}`：使用 `baseVersion` 编辑草稿。
- `POST /api/works/{workId}/narrative-plans/{planId}/publish`：使用 `baseVersion` 发布。

## 章节场景规划

- `POST /api/chapters/{chapterId}/scene-plan-candidates`：基于当前作品规划和章节大纲 revision 创建 Agent 候选任务。
- `GET /api/chapters/{chapterId}/scene-plan-candidates/latest`、`GET .../{planId}`：读取候选。
- `PUT .../{planId}`、`POST .../{planId}/abandon`、`POST .../{planId}/publish`：编辑、放弃或发布候选。
- `GET /api/chapters/{chapterId}/scene-plans/current`、`GET /api/chapters/{chapterId}/scene-plans/{planNo}`：读取当前或指定已发布版本。

候选和发布使用乐观锁。模型输出只保存结构化 ScenePlan，不保存隐藏推理；作品规划或章节大纲发生变化后不能发布旧候选。
