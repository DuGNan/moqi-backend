# 正文对话改写接口

## 适用范围

正文工作台在同一个输入框讨论或修改已保存正文。沿用选区协助接口，不改变旧 `discuss/rewrite/polish/expand/compress` 的语义。

## 发起对话

`POST /api/chapters/{chapterId}/selection-assistance`

- `operation: auto`：由模型依据作者本轮指令与该对象会话判断讨论或改写。
- `targetKind/targetId/targetVersion/contentHash`：绑定正式正文或候选的已保存版本。
- `selectionStart/selectionEnd/selectedText/referenceScope`：绑定原文范围。未引用时使用 `whole` 并冻结当前全文。
- `instruction`：作者自然语言输入。
- `parentId`：可选，继续调整未应用改写稿；必须同一对象、版本与原文范围。
- `idempotencyKey`：重放同一请求，不重复创建任务。

模型输出只允许单个 `advice` 或 `replacement` 字符串。讨论仅产生回答；改写产生可应用的 `diff`。结构未完成、内容为空、任务失败、取消或截断均不产生可应用 Diff。`auto` 不新建候选，不自动写回正文，不生成规划变更包。

## 流式与恢复

通过既有章节 SSE 发送带 `conversationId/taskId` 的 `reply.started`、`reply.delta`、`reply.completed`，增量只含解码后的可见内容。可见增量是预览，不代表可应用结果；完成后读取持久化消息及 `GET /api/selection-assistance/{id}` 的 Diff。失败和取消状态通过该持久化查询恢复，客户端不得继续提供替换入口。停止沿用 `POST /api/selection-assistance/{id}/cancel`。

## 替换与保存

替换是客户端可撤销编辑，只替换绑定范围。正文对象、版本、原文变化或对象只读时禁止应用。非改写回答没有替换入口；未应用改写可继续调整或拒绝。

正式正文 `PUT /api/chapters/{chapterId}/content` 支持可选 `appliedProposalIds: number[]`。服务端在章节行锁和保存事务内校验提案归属、源版本/哈希与待应用状态，保存正文并记录提案应用结果，任一冲突均回滚。省略该字段兼容旧调用。已发布正文不可原位保存。

候选沿用现有候选 CAS 保存与 `appliedProposalIds` 结算，不自动采纳、发布或更新规划。完整输出、写入保护和模型生成质量是独立验收项。
